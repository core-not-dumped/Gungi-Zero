# 10: 나노 군의 설정과 상태 공간 세기

**What to build:** 완전 탐색으로 풀 수 있는 나노 군의 규격 하나가 선택된다. 2.5단계가 이 규격 위에서 AlphaZero 를 군의 메커니즘으로 검증한다 — 틱택토 검증은 탑·단수 제약·쌓기 인코딩에 버그가 있어도 전부 통과하기 때문이다.

5×5 자체는 완전 탐색으로 풀 수 없다. 같은 규모의 5×5 미니쇼기도 미해결이다.

**Blocked by:** 07

**Status:** ready-for-agent

- [x] 나노 설정 후보 몇 개(판 크기 × 말 구성 조합)를 정의한다. 미니 군의와 같은 엔진·같은 행동 공간을 쓴다
- [ ] 후보마다 초기 국면에서 도달 가능한 상태 수를 센다
- [ ] 세는 데 너무 오래 걸리는 후보는 상한에서 중단하고 "완전 탐색 불가" 로 기록한다
- [x] 완전 탐색이 가능한 후보 하나를 고르고 근거(상태 수)를 적는다
- [x] 선택한 나노 설정으로 적합성 스위트가 통과하고 랜덤 대국이 끝난다
- [x] 완전 탐색 solver 와 AlphaZero 검증은 이 티켓이 아니다 (2.5단계)

## Comments

- 결과(2026-11-27): `docs/nano-state-space.md`. 3x4 帥·大·兵 (881,080 상태), 설정은 `games/nano_gungi.py`.
