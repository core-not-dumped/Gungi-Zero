# 09: perft 와 측정 보고

**What to build:** 랜덤 대국 1만 판의 통계가 나오고, 그 결과로 초기 배치와 말 개수가 확정된다. 1단계가 "만들었다" 가 아니라 "측정해서 정했다" 로 끝난다.

**Blocked by:** 07

**Status:** ready-for-agent

- [x] perft 가 초기 국면에서 깊이별 노드 수를 세고, 그 숫자가 고정값으로 테스트에 박힌다
- [x] 랜덤 대국 1만 판이 예외 없이 종료된다
- [x] 보고에 선수 승률, 무승부율, 평균·최대 대국 길이, 평균 분기 계수, 종료 사유 분포(`帥` 잡기 / 수 제한 / 반복 / 합법수 없음)가 들어간다
- [x] 시드를 고정해 보고가 재현된다
- [x] 보고를 근거로 초기 배치와 말 개수를 확정하고 설정 기본값을 갱신한다. 무승부로 수렴하면 말 개수를 늘리는 선택지를 검토한다
- [x] 보고를 근거로 200수와 반복 3회가 적절한지 판정한다. 바꾸면 ADR-0004 와 종료 규칙 버전 기록을 갱신한다 — Elo 비교는 같은 종료 규칙 안에서만 유효하다
