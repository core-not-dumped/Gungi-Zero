# 07: 쌓기와 단

**What to build:** 미니 군의가 완성된다. 말을 아군·적군 위에 쌓을 수 있고, 높이가 갑옷으로 작동한다. 이 티켓이 끝나면 2단계가 올라탈 룰 엔진이 완성된 것이다.

단수 제약이 군의 전술의 전부다. 이걸 빼면 남는 것은 이동 패턴이 이상한 장기이고, 3단계 학습 결과가 군의에 대해 아무것도 말해주지 않는다 (ADR-0002).

**Blocked by:** 06

**Status:** ready-for-agent

- [x] 최대 단 2까지 쌓을 수 있다. 아군 위에도 적군 위에도 쌓을 수 있고, 적군 위에 쌓는 것은 잡는 것이 아니다
- [x] 맨 위가 적 말인 칸에는 잡기와 쌓기가 **둘 다** 합법수다 (단수·`帥` 제약 안에서). 맨 위가 아군인 탑은 아래에 적이 있어도 잡을 수 없다
- [x] `Move` 가 쌓기 여부를 담고, 행동 공간이 1250 (`쌓기 × 625 + 출발 × 25 + 도착`) 이다. 정규형 변환은 쌓기 평면을 바꾸지 않는다 (ADR-0006)
- [x] 수 표기법이 이동·잡기 `b1-c3`, 쌓기 `b1-c3^` 이고 렌더와 파싱이 왕복한다. 로그의 `x` 는 잡기에만 붙는다
- [x] 단수 제약: 자기보다 높은 단의 말은 잡을 수도 쌓을 수도 없다. 한 번에 한 단씩만 오른다
- [x] 2단 말은 유한 방향 사거리가 1 늘고, 무제한 방향은 그대로다
- [x] 탑의 맨 위 말만 움직인다. 아래 말은 얼어 있고, 위가 비키면 다시 움직인다
- [x] 탑을 잡으면 그 칸의 적 말이 전부 잡히고 내 말은 남는다
- [x] `帥` 위에는 아군이든 적군이든 아무것도 쌓을 수 없다
- [x] 帥ツケ 금지: `帥` 자신은 다른 말 위로 올라갈 수 없다. 위 항목과 **다른 규칙**이며 따로 테스트한다
- [x] fixture: 쌓기 · 단수 제약 · 사거리 증가 · 맨 위만 이동 · 탑 잡기 · `帥` 위 금지 · 帥ツケ 금지 각각 최소 하나
- [x] 속성 테스트: 탑 높이가 설정된 최대 단을 넘지 않는다
- [x] 속성 테스트: `帥` 는 항상 자기 탑의 맨 위다
- [x] 미니 군의 기본 설정(5×5, `帥`1·`大`1·`槍`1·`兵`2, 최대 2단)으로 적합성 스위트가 통과하고 랜덤 대국이 끝난다

## Comments

- 결정(2026-11-26): 공식 규칙대로 적 칸에서 잡기와 쌓기를 고른다. 행동 공간은 625 에서 1250 으로 늘린다. 근거는 ADR-0006 과 `../research-original-rules.md`. 06 번이 남긴 `_fail_if_stackable` 임시 오류는 이 티켓에서 없앤다.
- 미니 군의 기본 설정은 `games.mini_gungi.MINI_GUNGI` 다. 규칙별 fixture 는 `tests/test_mini_gungi.py` 의 "쌓기와 단" 절에 있다 (08 번의 검토 대상).
- 帥ツケ 금지 때문에 `帥` 는 실제 대국에서 2단에 오르지 못한다. 사거리 표의 "帥 2단 = 2칸" 은 파싱한 판으로만 확인했고, `parse` 는 그런 판(`▲帥/▲兵`)을 여전히 받는다. 08 번 검토에서 판단한다.
