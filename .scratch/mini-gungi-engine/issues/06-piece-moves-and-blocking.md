# 06: 말 4종 이동표와 막힘 (1단)

**What to build:** `帥`·`大`·`槍`·`兵` 네 말이 1단에서 규칙대로 움직이고, 점유된 칸에 막힌다. 쌓기는 아직 없다(최대 단 1).

04 뒤에 두는 이유: 04 가 `Position` 구조를 바꾸므로, 이동 생성을 병렬로 만들면 같은 자료구조를 둘이 동시에 건드린다.

**Blocked by:** 04

**Status:** ready-for-agent

- [x] 1단 이동표: `帥` 8방향 1칸 · `大` 직선 무제한 + 대각 1 · `槍` 전방 2, 전방대각 1, 후방 1 (측면·후방대각 없음) · `兵` 전방 1 또는 후방 1
- [x] 사거리 표가 한 모듈에 데이터로 모여 있어 교체 가능하다. 공식 룰북의 컬러 이미지를 2차 자료가 재구성한 값이라 바뀔 수 있다
- [x] 막힘 판정이 술어 하나로 분리되어 있다. 점유된 칸은 단수와 무관하게 길을 막는다
- [x] `槍` 의 전방 2칸은 미끄러지며 중간에 말이 있으면 멈춘다. 뛰어넘지 않는다
- [x] 잡기는 이동과 같다. 별도의 잡기 패턴이 없다
- [x] 잡힌 말은 영구히 제외된다. 손패가 없고 `新` 은 존재하지 않는다
- [x] fixture: 이동표 4개, 막힘 1개, `槍` 슬라이드 1개. 각각 판 그림과 기대 합법수를 명시한다
- [x] 속성 테스트: 말 개수가 잡힌 만큼만 줄어든다
- [x] 네 말·최대 단 1 설정으로 적합성 스위트가 통과하고 랜덤 대국이 끝난다
