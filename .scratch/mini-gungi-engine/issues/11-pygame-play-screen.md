# 11: pygame 대국 화면

**What to build:** 사람이 마우스로 나노 군의를 둔다. 상대는 같은 화면의 다른 사람이거나 랜덤 AI 다. 이 티켓이 끝나면 규칙 해석을 직접 두어 보며 확인할 수 있다.

**Blocked by:** 10

**Status:** needs-triage

- [ ] `uv run python -m scripts.play` 로 창이 열린다. 상대(사람 / 랜덤 AI), 사람의 선후, 변형(기본은 나노, 미니도 선택), 랜덤 AI 시드를 고를 수 있다
- [ ] 판, 말, 둘 차례, 수 번호가 보인다. 2단 탑은 위아래 말과 각 주인이 모두 보인다
- [ ] 말을 누르면 갈 수 있는 칸이 표시되고, 다른 곳을 누르면 선택이 풀린다. 둘 수 없는 수는 두어지지 않는다
- [ ] 잡기와 쌓기가 모두 합법인 칸에서는 둘 중 하나를 고르게 한다
- [ ] 둔 수가 로그 표기(`b1-c3`, `b1-c3^`, 잡기는 `x`)로 남는다
- [ ] 대국이 끝나면 결과를 보여주고 새 대국을 시작할 수 있다
- [ ] 합법수·수 두기·결과는 `Game` 에 묻는다. `ui/` 는 규칙을 다시 구현하지 않고 `engine/` 을 직접 import 하지 않는다
- [ ] 랜덤 AI 는 `scripts/play.py` 가 주입한다
- [ ] 클릭을 수로 바꾸는 부분은 창 없이 테스트한다. CI 는 화면 없이 통과한다
- [ ] pygame 의존성을 추가한다

## Out of Scope

- 탐색 AI, 학습된 AI 와의 대국
- 무르기, 기보 저장·불러오기, 애니메이션, 소리
