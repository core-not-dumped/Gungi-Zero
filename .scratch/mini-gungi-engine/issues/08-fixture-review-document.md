# 08: fixture 사람 검토 문서

**What to build:** 사람이 코드를 읽지 않고 규칙 해석이 맞는지 판단할 수 있는 문서가 나온다.

에이전트가 룰 엔진과 기대 정답을 둘 다 썼으므로 같은 규칙 오해가 양쪽에 들어갔을 수 있다. 상관된 오류라 테스트를 몇 겹 쌓아도 잡히지 않는다. 이 검토가 유일한 방어선이다.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 채택한 규칙마다 fixture 가 하나 이상 모여 있다
- [ ] fixture 마다 판 그림(텍스트 렌더 형식)과 기대 합법수(`b1-c3` 표기)가 나란히 있다
- [ ] 각 fixture 가 어떤 규칙을 검증하는지 한 줄로 적혀 있다
- [ ] 문서는 테스트에서 생성되거나 테스트와 같은 출처를 쓴다. 손으로 옮겨 적어 갈라지지 않는다
- [ ] 사람 검토를 받는다. 지적된 오해가 있으면 룰 엔진과 fixture 양쪽을 고친다
