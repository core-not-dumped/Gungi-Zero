# 04: 종료 규칙 완성

**What to build:** 대국이 끝나는 세 경우가 모두 작동한다 — 수 제한, 같은 판 3회 반복, 합법수 없음. 반복을 세려면 판 모양만 비교해야 하므로, 경로를 들고 다니는 방식과 `board_key` 가 여기서 확정된다.

종료 규칙은 공식 군의 규칙이 아니라 발명한 것이다 (ADR-0004).

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] `Position` 이 판·차례·`ply`·경로상 국면들을 품고, 네 개 전부 동등성과 해시에 들어간다
- [ ] 경로는 연결 리스트로 공유되어 `apply_move` 가 복사를 하지 않는다
- [ ] `board_key` 는 판 + 차례다. 반복 횟수는 `board_key` 로 센다
- [ ] 같은 판이 3회 나타나면 무승부로 끝난다
- [ ] 합법수가 없으면 현재 플레이어의 패배다
- [ ] 종료 판정이 `Position` 만 보고 가능하다
- [ ] 속성 테스트: 경로가 달라도 판과 차례가 같으면 `board_key` 가 같다
- [ ] 속성 테스트: 판과 차례가 같고 경로가 다르면 `Position` 은 다르다
- [ ] 반복 fixture 는 파싱이 아니라 수를 실제로 두어 만든다. 파싱으로 만든 `Position` 의 반복 횟수는 0이다
- [ ] 텐서의 반복 횟수 평면과 수 진행도 평면이 채워진다
