# 04: 종료 규칙 완성

**What to build:** 대국이 끝나는 세 경우가 모두 작동한다 — 수 제한, 같은 판 3회 반복, 합법수 없음. 반복을 세려면 판 모양만 비교해야 하므로, 경로를 들고 다니는 방식과 `board_key` 가 여기서 확정된다.

종료 규칙은 공식 군의 규칙이 아니라 발명한 것이다 (ADR-0004).

**Blocked by:** 03

**Status:** ready-for-agent

- [x] `Position` 이 판·차례·`ply`·경로상 국면들을 품고, 네 개 전부 동등성과 해시에 들어간다
- [x] 경로는 연결 리스트로 공유되어 `apply_move` 가 복사를 하지 않는다
- [x] `board_key` 는 판 + 차례다. 반복 횟수는 `board_key` 로 센다
- [x] 같은 판이 3회 나타나면 무승부로 끝난다
- [x] 합법수가 없으면 현재 플레이어의 패배다
- [x] 종료 판정이 `Position` 만 보고 가능하다
- [x] 속성 테스트: 경로가 달라도 판과 차례가 같으면 `board_key` 가 같다
- [x] 속성 테스트: 판과 차례가 같고 경로가 다르면 `Position` 은 다르다
- [x] 반복 fixture 는 파싱이 아니라 수를 실제로 두어 만든다. 파싱으로 만든 `Position` 의 반복 횟수는 0이다
- [x] 텐서의 반복 횟수 평면과 수 진행도 평면이 채워진다

## Comments

- 종료 사유가 겹치면 帥 잡기, 합법수 없음(패배), 반복·수 제한(무승부) 순으로 판정한다. 스펙에는 순서가 없어 구현하며 정했고, 소유자가 확정해 ADR-0004 에 기록했다.
- 경로를 동등성에 넣으면 `parse(render(p)) == p` 가 성립하지 않아 스펙의 문장을 고쳤다. 적합성 스위트는 판·차례·`ply`·`board_key`·렌더가 같은지를 본다.
- `apply_move` 는 경로를 복사하지 않지만 O(1)은 아니어서 CLAUDE.md 와 스펙의 O(1) 문장을 고쳤다. 합법수 검사가 종료 판정을 거치고, 반복 횟수를 세느라 경로를 걷는다 (O(ply)). 4단계에서 증분 Zobrist 해시를 넣을 때 함께 없어진다.
- "합법수 없음" 은 帥 만 움직이는 지금은 만들 수 없어, 테스트가 엔진의 이동표를 비워서 확인한다 (06 번 티켓에서 교체).
