# 02: `games.base.Game` 프로토콜과 틱택토

**What to build:** 틱택토를 `Game` 으로 처음부터 끝까지 둘 수 있다. 프로토콜 모양이 여기서 결정되고, 군의가 아닌 게임으로 검증된다. 같은 테스트 스위트가 앞으로 붙는 모든 게임에 대해 "적합성" 의 정의가 된다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `games.base` 가 `Game`·`Position`·`Move` 를 정의한다. `Game` 은 상태를 갖지 않는다
- [ ] `Game` 연산: 초기 국면, 합법수, 수 두기, 종료 여부와 결과, 행동 공간 크기, 수→행동 인덱스, 행동 인덱스→수, 합법수 마스크, 정규형(국면과 행동 인덱스 양쪽), 판→텐서, 텍스트 렌더, 텍스트 파싱, `board_key`
- [ ] `Position` 은 불변이고 해시 가능하다. `Game` 프로토콜에 `undo` 는 없다
- [ ] 판→텐서가 `numpy.ndarray` 를 반환한다. PyTorch 를 import 하지 않는다
- [ ] 틱택토가 프로토콜을 구현한다
- [ ] 게임에 대해 파라미터화된 적합성 스위트가 있고 틱택토가 통과한다: 합법수 마스크와 합법수 목록 일치, 모든 합법수의 행동 인덱스 왕복, `parse(render(p)) == p`, `정규형(정규형(p)) == p`, 정규형이 합법수 집합을 대응해 옮김, 비종료 국면에는 합법수가 하나 이상, 종료 국면에는 결과가 정해져 있음
- [ ] 랜덤 AI 가 합법수 중 균등 무작위로 고르고 시드를 받는다
- [ ] 랜덤 대국 스크립트가 틱택토 한 판을 끝까지 돌린다
