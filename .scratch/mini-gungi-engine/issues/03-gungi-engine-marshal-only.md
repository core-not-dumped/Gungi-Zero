# 03: 군의 엔진 tracer bullet — 帥만

**What to build:** 帥 둘만 올라간 군의 변형을 끝까지 둘 수 있다. 판을 사람이 읽는 텍스트로 찍고 다시 읽을 수 있고, 수가 625 행동 인덱스로 왕복하고, 18장 텐서가 나온다.

帥 둘은 서로 피하면 영원히 안 끝난다. 그래서 수 제한과 상태 표현을 첫 군의 티켓에서 강제로 마주하게 된다 — 어려운 결정을 뒤로 미루지 않는 것이 이 티켓의 목적이다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] `engine/` 이 변형 설정(판 크기, 말 종류와 개수, 최대 단, 초기 배치, 수 제한, 반복 한도)을 받는다. 배치와 말 개수는 코드 상수가 아니다
- [ ] `engine/` 은 순수 Python 이다. numpy·torch·wandb·`games/`·`ai/` 를 import 하지 않는다
- [ ] 어댑터가 `engine/` 을 감싸고 행동 인덱스 변환과 텐서 인코딩을 소유한다
- [ ] `帥` 는 1단에서 8방향 1칸 움직이고 이동으로 잡는다. 적 `帥` 를 잡으면 승리한다
- [ ] 행동 공간이 출발 칸 × 도착 칸 = 625 이고 합법수가 전부 왕복 변환된다
- [ ] 판→텐서가 `(18, 5, 5)` 이고 평면의 합이 판 위 말 개수와 일치한다
- [ ] 텍스트 렌더가 스펙의 형식을 따른다 (`▲` 아래, `▽` 위, 탑은 `상단/하단`). 파싱이 같은 형식을 받고 왕복한다
- [ ] 수 표기법이 `b1-c3` 이고 로그와 테스트가 같은 표기를 쓴다
- [ ] 수 제한을 넘으면 무승부로 끝난다
- [ ] `帥`만 설정으로 적합성 스위트가 통과한다
- [ ] 랜덤 대국이 예외 없이 끝난다
