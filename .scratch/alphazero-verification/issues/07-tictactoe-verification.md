## Comments

- 결과(2026-11-27): harness 는 `eval/match.py` (`play_match`), 진단은 `eval/value_agreement.py`, 합성 루트는 `scripts/verify_tictactoe.py` 다. 완료 기준은 `tests/test_verify_tictactoe.py` 의 `slow` 테스트다.
- 학습 시드 0, 50세대: 선수 100무, 후수 100무, 가치 일치율 0.789, 자가 대국 5,000판 40,556수, 420초(Windows CPU, torch 스레드 1, 20 논리 코어).
- 420초는 5분을 넘어 CI 는 1세대 스모크(실제 설정, 200판과 진단까지, 승패는 보지 않음)로 내렸다. 5분 판단은 로컬 측정이고 CI 러너에서 재지 않았다.
- 처음 설정(첫 2수만 temperature 1, 채널 32, 50판, 버퍼 5세대, 20세대)은 통과하지 못했다. 시드 0~2 가 후수에서 100판 중 14~22판을 졌고, 60세대까지 늘려도 시드 0·1 이 1패·16패였다.
- 지금 설정(첫 9수, 채널 64, 100판, 버퍼 10세대, 50세대)은 학습 시드 0~9 가 45·50세대에서 모두 무패였다. 5세대마다 쟀고, 40세대에서는 시드 0 이 13패였다. 설정을 고른 시드와 확인한 시드는 0~2 가 겹치고 3~9 는 새 시드다.
- 가치 일치율은 가치를 가장 가까운 결과(±0.5 경계는 무)로 읽는다. 5,478 상태 중 승 2,836·패 1,574·무 1,068 이라 모두 "승" 이라 답하면 0.518 이다.

- 시드 0 의 200판에서 수열이 서로 다른 대국은 선수 5가지, 후수 60가지다. temperature 0 인 AI 는 동률이 아니면 같은 수를 두어, 다양성은 완벽한 상대의 선택에서만 나온다. spec 의 "100판이 서로 다른 대국" 은 틱택토 선수 자리에서는 이뤄지지 않는다. 같은 수를 `match/*/distinct` 로 기록한다.
