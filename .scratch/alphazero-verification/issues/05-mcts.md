# 05: MCTS 와 시험 국면

**What to build:** 원래 국면으로만 트리를 만드는 MCTS 가 있고, 학습과 무관한 시험 국면에서 맞는 수를 고른다. 백업 부호를 뒤집으면 그 시험들이 실패한다.

**Blocked by:** 01, 04

**Status:** ready-for-agent

- [ ] 트리는 원래 국면 `p` 로만 만들고 `canonical` 을 부르지 않는다. 입력은 `encode(p)`, 정책은 `to_canonical_action_index(p, i)` 로 짝지어 읽는다
- [ ] 가치는 둘 차례인 쪽 시점이고 한 단계마다 부호를 뒤집는다. 종료 노드는 `outcome` 으로 평가한다(반복·수 제한 무승부 포함). 전치표가 없다
- [ ] PUCT(c=1.25), 루트 Dirichlet 노이즈(켜고 끌 수 있다), temperature 에 따른 방문 수 기반 선택. 방문 분포를 정규형 프레임으로 돌려줄 수 있다
- [ ] MCTS AI 가 `AI` 프로토콜을 따른다
- [ ] 시험용 `Network`: 균등 정책, 가치 0
- [ ] 틱택토 한 수 승리·한 수 패배 회피 국면을 쓰고, `render` 로 사람 검토를 받는다(새 fixture). 선수 차례·후수 차례를 하나씩 둔다
- [ ] 나노 시험 국면 1·2 (spec 에 판과 둔 수가 있다, **사람 검토 완료 2026-11-27**): 국면 1 은 `b4-c4`(반복), 국면 2 는 `a3-a2`(帥 잡기)를 고른다. 테스트는 `parse` 한 시작 국면에서 수를 두어 만들고, 시험 국면의 합법수 목록(11개·9개)도 확인한다
- [ ] 백업 부호를 뒤집은 MCTS 로 위 시험이 모두 실패하는지 테스트한다

설계: spec "MCTS", "Testing Decisions / MCTS 시험 국면".
