# 03: solver 와 완벽한 상대

**What to build:** 공통 게임 인터페이스만 쓰는 solver 가 `board_key` 그래프를 후퇴 분석해 상태마다 이론값과 DTM 을 내고, 완벽한 상대가 그 답으로 둔다. 틱택토의 알려진 사실로 먼저 고정해, 뒤의 무패 판정이 기댈 기준을 믿을 수 있게 한다.

**Blocked by:** 01 (AI seam 과 eval 경계), 02 (`board_outcome`)

**Status:** ready-for-agent

- [ ] 고정값: 틱택토 시작 국면의 이론값은 무승부, 도달 가능 국면은 5,478 개
- [ ] 작은 나노 후보 3x3 帥兵(1,812 상태)을 CI 에서 푼다. 상태 수가 나노 상태 공간 문서와 같다. 표본 국면에서 solver 가 승이라 한 것을, 실제 게임 위 깊이 DTM 탐색(반복·수 제한 포함)으로 확인한다
- [ ] 수 제한 반영: `DTM ≤ 수 제한 − ply` 가 아니면 이론값은 무승부다. 테스트로 확인한다
- [ ] 반복 규칙과 값이 같은 이유(이기는 쪽은 DTM 이 줄어드는 수만 둔다)가 solver 의 docstring 에 있다
- [ ] 완벽한 상대가 `AI` 프로토콜을 따른다. 이기는 국면은 가장 빠른 승, 비기는 국면은 무승부 유지, 지는 국면은 가장 늦은 패 중에서 시드로 고른다
- [ ] 완벽한 상대끼리의 틱택토는 시드 0~99 모두 무승부다. 완벽한 상대는 랜덤 AI 에게 지지 않는다
