# 03: solver 와 완벽한 상대

**What to build:** 공통 게임 인터페이스만 쓰는 solver 가 `board_key` 그래프를 후퇴 분석해 상태마다 이론값과 DTM 을 내고, 완벽한 상대가 그 답으로 둔다. 틱택토의 알려진 사실로 먼저 고정해, 뒤의 무패 판정이 기댈 기준을 믿을 수 있게 한다.

**Blocked by:** 01 (AI seam 과 eval 경계), 02 (`board_outcome`)

**Status:** ready-for-agent

- [x] 고정값: 틱택토 시작 국면의 이론값은 무승부, 도달 가능 국면은 5,478 개
- [x] 작은 나노 후보 3x3 帥兵(1,812 상태)을 CI 에서 푼다. 상태 수가 나노 상태 공간 문서와 같다. 표본 국면에서 solver 가 승이라 한 것을, 실제 게임 위 깊이 DTM 탐색(반복·수 제한 포함)으로 확인한다
- [x] 수 제한 반영: `DTM ≤ 수 제한 − ply` 가 아니면 이론값은 무승부다. 테스트로 확인한다
- [x] 반복 규칙과 값이 같은 이유(이기는 쪽은 DTM 이 줄어드는 수만 둔다)가 solver 의 docstring 에 있다
- [x] 완벽한 상대가 `AI` 프로토콜을 따른다. 이기는 국면은 가장 빠른 승, 비기는 국면은 무승부 유지, 지는 국면은 가장 늦은 패 중에서 시드로 고른다
- [x] 완벽한 상대끼리의 틱택토는 시드 0~99 모두 무승부다. 완벽한 상대는 랜덤 AI 에게 지지 않는다

## Comments

- 결과(2026-11-27): solver 는 `eval/solver.py` (`solve(game, move_limit=...)`), 완벽한 상대는 `eval/perfect.py` 다. 수 제한은 `Game` 이 알려 주지 않아 게임을 고르는 쪽이 같은 값을 넘긴다. 다른 값을 넘겨도 검증하지 못한다.
- 작은 나노 후보의 시작 국면은 무승부이고 최대 DTM 은 5 다.
- 반복 논증의 한계: "`board_key` 위의 값 = 반복 3회 규칙 아래의 값" 은, 이기는 수순이 지날 판이 경로에 이미 두 번 나온 국면에서는 성립하지 않는다. 처음부터 두는 대국에서 완벽한 상대가 이기거나 비기는 쪽이면 영향이 없다. 상대가 이기는 수를 놓치며 같은 판을 돌아온 뒤에는, 지는 쪽의 완벽한 상대가 반복으로 비길 길을 놓칠 수 있다(추론이며 재현하지 않음). 07·09 의 판정에서 상대가 그만큼 약해질 수 있다.
- 08 에서 필요한 것: 풀이를 파일로 저장할 때 수 제한을 함께 기록한다. 승·무·패 국면 수와 최대 DTM 을 내는 접근자는 아직 없다.
