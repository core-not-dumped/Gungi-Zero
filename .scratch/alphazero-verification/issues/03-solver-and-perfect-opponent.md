# 03: solver 와 완벽한 상대 — 틱택토에서 고정

**What to build:** `games.base` 만 쓰는 범용 solver 가 `board_key` 그래프를 후퇴 분석해 이론값과 DTM 을 낸다. 완벽한 상대가 그 답으로 둔다. 틱택토에서 먼저 믿을 수 있게 만든다.

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] `eval/` 의 solver: BFS 로 도달 그래프를 만들고(대표 `Position` 하나씩) 상태마다 승·무·패와 DTM 을 구한다. docstring 에 반복 규칙과 값이 같은 이유(이기는 쪽은 DTM 이 줄어드는 수만 둔다)를 적는다
- [ ] 수 제한 반영: 실제 이론값은 `DTM ≤ 수 제한 − ply` 이면 solver 값이고 아니면 무승부다
- [ ] 고정값 테스트: 틱택토 시작 국면 이론값 무승부, 도달 가능 국면 5,478 개
- [ ] 작은 나노 후보 3x3 帥兵 (1,812 상태)를 CI 에서 푼다. 표본 국면의 승을 실제 `Game` 위 깊이 `DTM` 탐색(반복·수 제한 포함)으로 독립 확인한다
- [ ] 완벽한 상대(`AI`): 이기는 국면은 가장 빠른 승, 비기는 국면은 무승부 유지, 지는 국면은 가장 늦은 패 중에서 시드로 고른다
- [ ] 완벽한 상대끼리의 틱택토는 시드 0~99 모두 무승부다. 완벽한 상대는 랜덤 AI 에게 지지 않는다

설계: spec "Solver 와 완벽한 상대", "Testing Decisions / Solver".
