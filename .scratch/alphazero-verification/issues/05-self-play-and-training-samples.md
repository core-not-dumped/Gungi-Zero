# 05: 자가 대국과 학습 샘플

**What to build:** MCTS AI 가 자기 자신과 한 판을 두면 `Episode` 와 수마다의 학습 샘플이 나온다. 가치 타깃 부호와 방문 분포의 정규형 프레임이 학습과 무관하게 이 자리에서 시험된다. 시험용 신경망으로 돈다.

**Blocked by:** 04 (MCTS 와 시험 국면)

**Status:** ready-for-agent

- [x] 자가 대국이 `Episode`(지금 그대로)와 수마다의 학습 샘플(정규형 입력, 정규형 합법수 마스크, 정규형 방문 분포, 가치 타깃)을 돌려준다
- [x] 자가 대국은 루트 Dirichlet 노이즈와 temperature 일정(틱택토 첫 2수, 나노 첫 4수는 1, 그 뒤 0)을 쓴다
- [x] 가치 타깃: 선수 승 대국에서 선수 차례 샘플은 +1, 후수 차례 샘플은 −1, 무승부 대국(반복·수 제한 포함)은 모두 0
- [x] 방문 분포: 후수 차례 국면에서 질량이 정규형 합법수 마스크 안에만 있다. 원래 프레임 인덱스로 저장하면 실패하는 국면을 골라 시험한다
- [x] 거울 증강을 쓰지 않는다 (ADR-0005)
- [x] 같은 시드의 자가 대국은 같은 `Episode` 와 학습 샘플을 낸다
- [x] Dirichlet α 를 설정에 두고 옆에 출처를 주석으로 단다: 틱택토 평균 합법수 5.569(랜덤 1만 판, 시드 0~9999) → 1.80, 나노 9.218(측정 보고 도구, 같은 시드) → 1.08

## Comments

- 결과(2026-11-27): 자가 대국은 `ai/self_play.py` (`play_self_play_episode`, `SelfPlayConfig`, `TrainingSample`, `SelfPlayResult`), 게임별 설정은 `scripts/hyperparameters.py` 다.
- 시험은 탐색 횟수를 16 으로 줄여 돈다. 나노에서 반복 무승부 대국이 필요한 시험만 50 이다 — 16회로는 시드 0~199 가 모두 帥 잡기로 끝났다.
- 같은 시드의 재현은 균등 시험용 신경망으로 확인했다. 실제 신경망과의 재현은 06 의 몫이다.
- 06 에서 쓸 것: 대국마다 다른 `seed` 를 넘긴다. 신경망의 평가 모드 전환은 부르는 쪽이 한다. `TrainingSample` 의 배열은 numpy 이고 torch 변환과 배치는 아직 없다.
