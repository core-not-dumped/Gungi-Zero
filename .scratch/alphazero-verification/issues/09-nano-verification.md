# 09: 나노 군의 검증 — 2.5단계 완료 기준

**What to build:** 나노 군의로 학습한 MCTS AI 가 완벽한 상대를 상대로 시험 판의 이론값을 지키고 3수 퍼즐을 풀며, 쌓기가 걸린 국면의 성적이 전체와 따로 보고된다. 틱택토 통과 전에는 GPU 시간을 쓰지 않는다는 순서 결정으로 07 을 기다린다.

**Blocked by:** 07 (틱택토 검증), 08 (나노 군의 풀기)

**결정:** ADR-0007. 풀이와 수치는 `docs/nano-solution.md`. 학습하지 않은 MCTS(탐색 100)는 시험 판 200개 중 76개를 통과한다

**Status:** ready-for-agent

- [ ] wandb 로거가 합성 루트에 있고 주입된다. 변형 설정을 config 로 남긴다. 로컬 GPU 에서 학습한다(CI 아님)
- [ ] 자가 대국의 시작: 판마다 25% 는 시작 국면, 75% 는 도달 가능하고 끝나지 않은 상태에서 균등하게 뽑은 국면(가장 짧은 경로와 그 `ply`). 뽑을 때 풀이를 쓰지 않는다. 합성 루트가 주입하고, 비율을 config 에 남긴다. 틱택토의 자가 대국과 같은 시드의 결과는 바뀌지 않는다
- [ ] 완료 기준 1, 시험 판: `scripts.nano_trials.nano_trials` 의 200판. 판마다 둘 차례인 쪽이 MCTS AI(temperature 0, 탐색 100), 상대는 완벽한 상대(시드 = 순번 0~199). 무승부 100판은 지지 않고, 승리 100판은 수 제한 안에 이긴다
- [ ] 완료 기준 2, 3수 퍼즐: 시작 국면에서 MCTS AI 가 `a1-a3^` 를 두고, 응수 7개 각각에 다음 수에 帥 를 잡는다. 시험 판과 따로 보고한다
- [ ] 층(`scripts.nano_trials` 의 8개)마다의 성적을 따로 적는다
- [ ] 진단: 도달 가능 881,080 국면에서 가치 머리의 승·무·패 일치율
- [ ] 진단: 쌓기가 걸린 국면(2단 탑이 있거나 쌓기가 합법)만의 MCTS 최선수 비율을 전체 비율과 나란히 적는다
- [ ] 결과 보고서를 남긴다: 세대 수, 학습 시간, 하이퍼파라미터, 위 수치, 검증하지 못한 것(槍, 兵 끼리의 만남)
- [ ] 통과하면 CLAUDE.md 의 진행 단계를 갱신한다
