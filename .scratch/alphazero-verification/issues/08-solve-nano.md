# 08: 나노 군의 풀기

**What to build:** 3x4 帥·大·兵 나노 군의의 이론값이 파일로 저장되어 있고, 시작 국면의 이론값과 최대 DTM 이 문서에 있다. 완벽한 상대가 그 파일로 나노 군의를 둔다.

**Blocked by:** 03 (solver 와 완벽한 상대)

**Status:** ready-for-agent

- [ ] 스크립트가 나노 군의를 풀어 파일로 저장한다(git 제외). 다시 만드는 명령을 문서에 적는다
- [ ] 상태 수가 881,080 으로 나노 상태 공간 문서와 같다
- [ ] 시작 국면의 이론값, 최대 DTM, 승·무·패 국면 수, 걸린 시간을 문서에 적는다
- [ ] 최대 DTM 과 수 제한 200 의 관계를 적는다. DTM 이 남은 수보다 길어 무승부가 되는 국면이 있는지 본다
- [ ] 완벽한 상대끼리의 나노 대국이 시작 국면의 이론값으로 끝난다(시드 몇 개)

spec: "Solver 와 완벽한 상대".
