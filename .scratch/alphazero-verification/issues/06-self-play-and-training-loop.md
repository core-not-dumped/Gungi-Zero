# 06: 자가 대국, 학습 루프, 로거

**What to build:** 현재 신경망으로 자가 대국 → 리플레이 버퍼 → 학습을 한 세대로 도는 루프가 있다. 로거는 주입받고, 체크포인트가 세대마다 남는다.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 자가 대국이 `Episode` 와 ply 마다의 학습 샘플(정규형 입력, 정규형 마스크, 정규형 방문 분포, 가치 타깃)을 돌려준다
- [ ] 자가 대국의 학습 샘플 seam 테스트 (spec "Seam", 소유자 확인 2026-11-27):
  - 가치 타깃: 선수 승 대국에서 선수 차례 샘플 +1, 후수 차례 샘플 −1, 무승부 대국은 모두 0
  - 방문 분포: 후수 차례 국면에서 질량이 정규형 합법수 마스크 안에만 있다. 원래 프레임 인덱스로 저장하면 실패하는 국면을 고른다
- [ ] 동기 세대 루프(N판 → 최근 K세대 버퍼 → M스텝), gating 없음. 손실은 정책 CE + 가치 MSE, Adam lr 1e-3, wd 1e-4
- [ ] `ai/` 의 `Logger` 프로토콜(`config`, `log`)과 메모리 로거. 손실·자가 대국 통계(길이, 결과 분포, 종료 사유)를 기록한다
- [ ] 하이퍼파라미터 설정(spec 표). **Dirichlet α 옆에 측정값과 출처를 주석으로 단다**: 틱택토 평균 합법수 5.569(랜덤 1만 판, 시드 0~9999) → 1.80, 나노 9.218(`measure(NANO_GUNGI, 10000, 0)`) → 1.08
- [ ] 세대마다 체크포인트를 로컬에 저장한다(git 제외)
- [ ] Python·numpy·torch 시드 고정. 같은 시드는 CPU 에서 같은 세대 가중치를 만든다

설계: spec "자가 대국과 학습 루프", "로거", "기본 하이퍼파라미터".
