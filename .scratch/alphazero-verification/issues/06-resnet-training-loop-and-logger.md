# 06: ResNet, 학습 루프, 로거

**What to build:** 작은 ResNet 으로 틱택토의 세대 하나(자가 대국 → 리플레이 버퍼 → 학습)를 끝까지 돌리는 스크립트가 메모리 로거로 돌고, 체크포인트를 남긴다.

**Blocked by:** 05 (자가 대국과 학습 샘플)

**Status:** ready-for-agent

- [ ] 작은 ResNet(정책 머리 + tanh 가치 머리, 블록 수·채널 수 설정)이 `Network` 프로토콜을 따른다. 틱택토 `(2, 3, 3)`·9 와 나노 `(18, 4, 3)`·288 의 모양으로 돈다. 신경망 단독 테스트는 모양과 시드 재현성만 본다
- [ ] numpy → torch 변환, 배치, 디바이스 처리가 학습하는 쪽 한 곳에 있다
- [ ] 동기 세대 루프(N판 → 최근 K세대 리플레이 버퍼 → M스텝), gating 없음. 손실은 정책 교차 엔트로피 + 가치 평균제곱오차, Adam lr 1e-3, weight decay 1e-4
- [ ] 로거 프로토콜(`config`, `log`)과 메모리 로거. 손실과 자가 대국 통계(길이, 결과 분포, 종료 사유)를 기록한다
- [ ] 합성 루트가 변형 설정(수 제한, 반복 한도, 판 크기, 말 구성)을 config 로 남긴다 (ADR-0004)
- [ ] 세대마다 체크포인트를 로컬에 저장한다(git 제외)
- [ ] 같은 시드는 CPU 에서 같은 세대 가중치를 만든다

spec: "신경망 프로토콜", "자가 대국과 학습 루프", "로거".
