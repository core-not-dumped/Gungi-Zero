# 거울 증강을 쓰지 않는다

미니 군의의 규칙은 좌우 대칭이다 — 帥 8방향, 大 직선+대각, 槍 전방·전방대각·후방, 兵 전후 모두 좌우 미러에 불변이다. 따라서 어떤 국면 `p` 에 대해 `mirror(p)` 의 최적 정책·가치는 `p` 의 것을 미러한 것과 같고, **거울 증강 데이터 자체는 올바르다.** 이 정당성은 **룰의 대칭성**에서 나오며 초기 배치의 대칭성과는 무관하다.

그런데도 쓰지 않는다. 채택한 초기 배치(`· 大 帥 槍 ·`)가 좌우 대칭이 아니므로 `mirror(p)` 는 규칙상 합법이고 라벨도 정확하지만, **우리 시작 국면에서 실제로는 거의 등장하지 않는 분포 밖 국면**이다. 즉 문제는 정확성이 아니라 이득의 크기다. 신경망 용량을 마주치지 않을 입력에 쓰는 대가로 데이터를 2배 얻는 셈이고, 5×5·말 5개 규모에서는 자가 대국이 싸므로 **그냥 더 돌리는 쪽이 단순하고 이득도 크다**.

## Considered Options

- **초기 배치를 좌우 대칭으로 바꿔 증강을 분포 안으로 들인다**: 하나뿐인 말(帥·大)이 전부 중앙 열에 몰려야 하고, 그 결과 1수 大↔大 강제 교환이 생기거나(帥 뒤·大 앞) 大 가 자기 帥 에 막힌다(大 뒤·帥 앞). 배치를 측정 후 조정할 노브로 두는 자유도까지 잃는다.

## Consequences

학습 파이프라인에 증강 단계를 넣지 않는다. "룰이 대칭이니 공짜 2배" 로 보고 나중에 끼워넣는 일을 막기 위해 `CLAUDE.md` 원칙에 명시한다.

6단계 9×9 에서 다시 본다. 그쪽은 자가 대국이 비싸서 2배가 실제 값어치를 하고, 입문 룰의 고정 배치를 좌우 대칭으로 고를 수 있다면 분포 문제도 사라진다.
