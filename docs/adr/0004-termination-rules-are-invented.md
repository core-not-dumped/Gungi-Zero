# 미니 군의의 종료 규칙은 공식 규칙이 아니라 우리가 발명한 것이다

공식 군의 규칙에는 **수 제한도, 스테일메이트 규칙도, 사석(dead position) 규칙도 없다.** 정의된 유일한 반복 규칙은 "동일 국면 4회 → 千日手 → **재대국**" 이며, 점수가 매겨지는 무승부가 아니다.

강화학습은 모든 대국이 유한하고 결과가 스칼라여야 한다. 미니 군의는 잡힌 말이 재사용되지 않아 말이 줄어들기만 하지만 帥 둘만 남으면 영원히 서로를 피할 수 있다. 그래서 다음을 **발명한다**:

- 200수 초과 → 무승부, 가치 타깃 0
- 동일 국면 3회 반복 → 무승부
- 합법수 없음 → 패배

세 가지 모두 공식 규칙에 근거가 없다. 세 번째는 장기 관례를 빌린 것이고, 공식 규칙은 이 상황을 아예 정의하지 않는다.

## Consequences

미니 군의의 대국 결과 분포는 공식 군의와 비교할 수 없다. 200 과 3 은 임의의 값이며 1단계가 끝나고 실제 대국 길이 분포를 보고 조정한다.

조정하면 학습 데이터의 무승부 비율이 바뀐다. 따라서 **세대 간 Elo 비교는 같은 종료 규칙 안에서만 유효하다.** 종료 규칙을 바꾸면 그 이전 세대의 Elo 는 이후 세대와 같은 축에 놓을 수 없고, wandb 기록에 종료 규칙 버전을 남겨야 한다.

반복 판정이 필요하므로 `Position` 은 해시 가능해야 한다. 이는 불변 `Position` 설계와 맞물려 있다.
