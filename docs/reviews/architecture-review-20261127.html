문제 — 정규형 프레임을 쓰라고 안내하지만, 어떤 연산이 프레임에 따라 달라지는지는 interface 에 없다.

해결 — 프레임·부호·합법수 순서·오류 약속을 interface 에 적고 파라미터화된 suite 로 고정한다.

  • 부호 버그가 한 seam 에서 드러남
  • leverage: 테스트 하나, 게임 다섯
  • MCTS 전에 locality 확보
  • render/parse 왕복도 suite 가 확인

ADR-0003 과 충돌 없음. 정규형 결정은 유지하고 약속만 명시한다.

문제 — loop 이 랜덤 AI 에 묶여 있고 기록이 얕아서, 쓰는 쪽마다 대국을 다시 둔다.

해결 — 수를 고르는 쪽을 받아 한 판을 두고 필요한 것을 남기는 module 하나로 모은다.

  • adapter 둘 이상: 실제 seam
  • locality: 부호 규칙 한 곳
  • 재생 loop 중복 제거
  • 틱택토로 loop 전체 테스트

ADR-0001 유지: 종료 사유·로그 표기는 ai/ 가 아니라 주입으로 받는다. ADR-0004 의 종료 규칙 버전 기록도 놓일 자리가 아직 없다.

  • 기존 적합성 테스트가 회귀 감시
  • 테스트의 가짜 수 파싱 제거

ADR-0001 유지: ui/ 는 계속 어댑터를 통해서만 본다. canonical 의 경로 회전(반복 횟수 보존)은 그대로 필요하다.
